# Demo guide

1. Double-click `start.bat` (works with Wi-Fi off). Chrome opens http://localhost:8000 after about 15 s.
2. Check the panel says **🔒 On-device · nothing recorded**.
3. Set the call language (Hindi for S1, Punjabi for S11, English for G2).
4. Press **Start listening** (or Space). Allow the mic the first time.
5. Play `demo-audio/S1_full.wav` on a phone on speaker next to the laptop.
6. Watch: lines appear, steps light up, the ring fills; the alarm fires at sentence 3, before money is asked.
7. Press **Stop** (or Space): the call text is wiped and a one-line summary is shown.
8. Play `G2_full.wav` with English selected: it stays green.

If the page looks old, press Ctrl+Shift+R. If the server is not found, start it again with `start.bat`.
